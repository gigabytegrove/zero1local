# Zero1Local release history

The [GitHub Releases page](https://github.com/gigabytegrove/zero1local/releases) is the authoritative download source. This is a historical index, not an instruction to downgrade. Always verify the exact package SHA-256 and read the corresponding release notes before installing.

## Historical integrity and channel rules

- Historical packages, checksums, tags, and source provenance must remain intact; changing a release title or note must not overwrite an existing ZIP.
- v1.4.14a is an archived Alpha build and must not be represented as a stable release. v1.3.0, v1.3.1 and v1.3.2 were published as prereleases.
- A GitHub non-prerelease flag indicates publication channel, not proof that every NAS hardware combination was independently certified. Preserve failure and rollback disclosures in individual historical notes.
- The in-app updater selects releases according to its configured channel. The exact published asset name and checksum must match the intended version.
