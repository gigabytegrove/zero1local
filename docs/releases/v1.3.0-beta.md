# Zero1Local v1.3.0 — Beta / release candidate

**Channel:** Beta (GitHub prerelease; NOT promoted to Stable)
**Target hardware:** supported Zero1 / IronCow ARM64 NAS appliances
**Full editable source:** private `gigabytegrove/zero1local-source`, commit `6d2d39db4476a32a7348f6a821f0891ab583d8fe`
**Production ZIP SHA-256:** `986a1a5ec2a906fe23d94e796fa50203339f4851701ebc79d1f082fc708604c2`

## Changes

- Removed the retired **native Google Drive sync/OAuth experience** from the v1.3.0 production runtime; local backup, restore and replication remain part of the core product.
- Removed ordinary-owner Zero1Connect pairing/tunnel controls and suppressed the obsolete remote-connect API in the candidate implementation; experimental networking features remain excluded from production.
- Syncria is an **optional companion in development** and is presented as **Coming soon** only. No Syncria dependency or actual connector is bundled in v1.3.0.
- Maintained the existing NAS management functionality and self-contained application updater.

## Verification completed before publication

- Source-side Go tests, vet, ARM64 builds, JavaScript syntax checks and web route validations passed in the candidate build environment.
- A source-level route and handler review was performed for removed/disabled legacy integrations.
- Public archive verifier: `STATIC_PASS_NEEDS_SOURCE_AND_HARDWARE_TESTS` on the exact candidate, 81 runtime files inspected with no native Google Drive markers detected.
- Public ZIP checksums verified and matched before release; publication workflow checks both locally rebuilt and freshly downloaded asset SHA-256.

## Qualification still needed

This **prerelease has not yet passed a real NAS upgrade, storage/data-preservation test or rollback drill**. Before installing, back up all NAS configurations and critical data independently. Do not install on storage appliances without a recovery plan. Use Beta, not Stable, and verify your appliance's exact model and version first.

If you still use Zero1Local's **built-in Google Drive sync**, do not install this build expecting those jobs to continue. The feature was retired; legacy configuration should remain inert. Syncria functionality is not yet present.

The existing `v1.2.9.15` production ZIP remains available for the previous Stable channel pending live v1.3 validation.
